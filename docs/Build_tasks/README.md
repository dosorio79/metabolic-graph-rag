# Build Tasks Diary

This folder is the historical build diary for the project.

Use these files when you want to understand:

- how the project was originally broken into milestones
- what was considered in scope at each stage
- how the architecture and orchestration story evolved over time
- why some archived or superseded decisions still exist in the repository

## How This Differs From The Tutorial

The diary is historical.

- it may contain superseded steps
- it may refer to earlier examples such as `hsa00010`
- it may reflect older orchestration emphasis, including Airflow-first stages
- it is useful for project context, not as the cleanest way to learn the system

The current guided learning path lives in:

- [docs/tutorial/README.md](../tutorial/README.md)

## Suggested Use

- Read the tutorial first if you want the current recommended path.
- Read this diary second if you want the implementation history and milestone
  framing.
